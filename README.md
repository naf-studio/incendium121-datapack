# NAF Studio - Incendium121 Datapack

This datapack modifies the coordinate scale of The Nether to `1.0`. This ensures that traveling 1 block in the Nether is exactly equivalent to traveling 1 block in the Overworld, overriding the default 1:8 vanilla Minecraft ratio.

> [!NOTE]
> This is an internal datapack tailored specifically for the NAFMC server and may not function properly on other servers. Its configuration relies directly on the base Incendium datapack installed on NAFMC.

## 1. Features

- Explicitly sets the `coordinate_scale` of The Nether dimension to `1.0`.
- Nether portals and spawn mechanics map precisely 1:1 with the Overworld.

## 2. Installation

1. Download the `incendium121.zip` file from the releases page.
2. Place the `.zip` file into the `datapacks` directory of your Minecraft world.
