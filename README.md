# 1:1 Nether Coordinate Scale Datapack

This datapack modifies the coordinate scale of The Nether to `1.0`. This ensures that traveling 1 block in the Nether is exactly equivalent to traveling 1 block in the Overworld, overriding the default 1:8 vanilla Minecraft ratio.

## Features

- **1:1 Coordinate Mapping:** Explicitly sets the `coordinate_scale` of The Nether dimension to `1.0`.
- **Universal Compatibility:** Seamlessly works on both singleplayer worlds and multiplayer servers.
- **Accurate Portal Linkage:** Nether portals and spawn mechanics map precisely 1:1 with the Overworld.

## Installation

1. Download the `incendium121.zip` file from the [Releases](../../releases) page.
2. Place the `.zip` file into the `datapacks` directory of your Minecraft world:
   - **Singleplayer:** `.minecraft/saves/<world_name>/datapacks/`
   - **Multiplayer Server:** `<server_directory>/world/datapacks/`
3. Execute the `/reload` command in-game or restart your server to apply the changes.
